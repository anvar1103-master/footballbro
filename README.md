# Голазо! (Golazo)

**Нарисуй свой лучший гол.** Футбольная головоломка в духе Score! Hero: каждый уровень — застывший момент матча.
Ты проводишь линию от мяча — мышкой или пальцем:

- линия кончается **в воротах** — удар точно в эту точку;
- линия кончается **на газоне** — пас туда (по земле резкий, в ноги или на ход партнёру);
- **изогни линию** — мяч закрутится (сухой лист, банан в обход стенки);
- на пути паса соперник — мяч пойдёт **навесом** (или включи «⤴ НАВЕС»); красный крестик покажет, где пас перехватят.

Партнёры делают забегания (пунктирные стрелки), защитники перекрывают, вратарь читает удар и прыгает — кручёный мяч он
видит хуже. Дошёл мяч до партнёра — время снова замирает: бей с его позиции, с лёта или головой. За гол — очки
(кручёный, в девятку, с лёта, головой, издалека, пасы, в одно касание) и до трёх звёзд.

- **Карьера:** 30 уровней в трёх главах — атаки, пасы на ход, стенки, навесы, угловые, контратаки, штрафные со стенкой, пенальти.
- **Штрафные на выживание:** бесконечная серия штрафных, 3 жизни; с каждым голом дальше, стенка выше, вратарь сильнее.
  Попадание в розовую мишень — +500.
- **Серия пенальти:** 5 ударов на команду, потом до первого промаха. Когда бьёт соперник, ты — вратарь: пока он
  разбегается, проведи линию туда, куда прыгнуть.
- Повторы голов, замедление у ворот, живая сетка, стадион на закате, краш-тест манекены.
- Управление: только мышь/палец. R — заново, Esc — меню, M — звук, ←/→ — повернуть камеру, C — вид сверху, Пробел — навес.

Запуск: `npm install && npm run dev` → http://localhost:5173 (`?level=N` — сразу уровень, `?all` — открыть все).

# Footballbro (предыдущая игра)

`party.html` (http://localhost:5173/party.html).

**Footballbro** — угарный аркадный футбол краш-тест манекенов на «шатающейся» физике. Финты (радуга, финт с уходом,
разворот), удары в угол с подкруткой, с лёта, через себя и головой, подкаты, хватание за майку, вратари, повторы голов.
Крытый манеж: газон, светодиодные борта и табло, стеклянные стены до потолка — мяч отскакивает и не уходит в аут.

- **Камера-трансляция** сбоку ведёт мяч (твоя атака — вправо); мяч крупный, виден сквозь игроков, в воздухе — кольцо, куда упадёт.
- **Три режима** (выбор в меню):
  - **Тренер** (по умолчанию): игроки сами бегают, открываются и отбирают мяч по твоей тактике (схема, стиль: пасы /
    контратака / навал, прессинг). Ты только кликаешь: **ЛКМ** — пас в точку, **ПКМ** — удар в точку (держи — сильнее;
    по сопернику с мячом — прессинг), **Пробел** — навес, **Shift+ЛКМ** — рывок партнёра в точку, колёсико — финт.
    Пока кнопка зажата, время замедляется. Тактику можно менять и на паузе (Esc).
  - **Капитан** — ведёшь своего игрока мышкой (описание ниже).
  - **Футболист** — классика с клавиатуры (таблица ниже).
- **Капитан — управление только мышью**: игрок бежит туда, где курсор (далеко — быстрее), **ЛКМ** — пас в точку клика,
  **ПКМ** — удар в точку клика (держи — сильнее), колёсико/Пробел — финт, клик колёсиком — навес. Без мяча ЛКМ — рывок,
  ПКМ рядом с соперником — подкат. Партнёры бегают и открываются под пас сами. Клавиатурные раскладки остались в меню.
- **Две главные кнопки:** пас и удар. Без мяча пас = смена игрока, удар = подкат. Рядом с игроком подсказки: что сейчас
  делают кнопки и кому уйдёт пас (белое кольцо под партнёром).
- **ОГОНЬ:** пасы, финты, отборы и сейвы заполняют шкалу; когда она полная, следующий удар огненный — сносит всех на пути, даже вратаря.
- **Обучение** из меню: 6 коротких упражнений (бег, пас, удар, отбор, финт, огненный удар).

| Действие | Мышь + клавиатура (по умолчанию) | Только клавиатура |
|---|---|---|
| Бег / спринт | WASD или стрелки / Shift | стрелки / Shift |
| Пас (без мяча — сменить игрока) | ЛКМ (в курсор) или J | S |
| Удар — держи, чтобы сильнее (без мяча у соперника — подкат) | ПКМ (в курсор) или K | D |
| Навес / парашют | колесо, C или L | A |
| Финт: вперёд — радуга, вбок — уход, назад — разворот | F | W / F |
| Подкат · схватить за майку · смена игрока | E · R · Q | E · R · Q |
| Прыжок | Пробел | Пробел |

С клавиатуры удар сам летит в угол ворот, подальше от вратаря; мимо штанги — закрутит в ворота.
V — камера (трансляция / сверху-сзади / близко), Esc — пауза, M — звук.
Запуск: `npm install && npm run dev` → http://localhost:5173.

## Soccerbro (старая версия в стиле FIFA)

Лежит в том же репозитории как архив и источник готового кода: `classic.html` (http://localhost:5173/classic.html).

Мультяшный 3D-футбол в браузере: реалистичная физика мяча (сопротивление воздуха, эффект Магнуса — крученые удары как finesse в FIFA, отскоки с вращением), живая сетка ворот (ткань, которая прогибается и колышется), повторы голов, синтезированные звуки стадиона.

## Управление

Раскладку можно поменять в **Настройках** (две готовые: «Как в FIFA» и «WASD + JKL», плюс переназначение любой клавиши).
По умолчанию — как в FIFA на клавиатуре:

| Клавиша | С мячом | Без мяча |
|---|---|---|
| Стрелки | бег | бег |
| E | спринт (тратит выносливость) | спринт |
| S | пас (держать — дальше и сильнее) | сдерживание (держать) |
| W | пас на ход | прессинг партнёром (держать) |
| A | навес / заброс | подкат |
| D | удар (держать — сильнее) | отбор |
| Shift | **крученый удар (finesse)** | — |
| Z | удар парашютом | — |
| C | финт | — |
| Q | — | смена игрока |
| V / M / Esc | камера / звук / пауза | |

Геймпад: левый стик, A — пас, B — удар, RB — крученый, LT — парашют, X — на ход, Y — навес, LB — смена, RT — спринт, R3 — финт.

## Режимы
- Формат 5×5, 7×7, 11×11 (размер поля подстраивается)
- Длина тайма 1.5 / 2.5 / 4 минуты
- Сложность ИИ: легко / норм / сложно
- «Смотреть ИИ vs ИИ»

Правила: голы, ауты, угловые, удары от ворот, штрафные и пенальти за фолы, два тайма. Офсайдов и карточек нет.
